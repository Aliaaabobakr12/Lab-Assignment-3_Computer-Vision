**🎨 Ishihara Color Blindness Test Image Processor**

This project implements a custom K-Means clustering algorithm from scratch and applies it to the segmentation and analysis of Ishihara color blindness test plates. The aim is to extract distinguishable color regions that may help assess how individuals with color vision deficiencies perceive the images.

Features
  Custom implementation of the K-Means clustering algorithm
  Image segmentation in CIE Lab color space
  Creation of binary masks for each cluster using Otsu thresholding
  Visualization of:
    Original image
    Segmented image
    Color-masked clusters
